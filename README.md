# EventFlow

**Event & Registration Management System**

EventFlow is a front-end web application that helps organizations, schools, clubs, and small event organizers manage events and participant registrations from a single dashboard.


## Future Improvements

- Export events and participant lists to CSV
- Email/SMS reminder simulation for upcoming events
- Multi-organizer accounts with role-based permissions
- Calendar view for events
- Drag-and-drop event status updates (Kanban-style)
- Dark mode
